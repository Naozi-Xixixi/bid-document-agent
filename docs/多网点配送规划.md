# 多网点多车辆配送规划

> 已新增拆单、多趟、跨日、容积和冷链的离线模拟，以及独立的小规模货车约束规划；这些尚未自动接入本页面的原有规划。详见 [高级配送约束模拟](./高级配送约束模拟.md)。

首页进入「示例配送公司配送路线图」，默认显示多网点规划。原有网点维护及单路线页面可通过「维护网点 / 使用旧版路线」进入。真实网点资料需要企业确认后录入；系统不会把虚构数据保存为网点。

点击「运行虚构网点测试」可在没有高德 Key 或真实资料的情况下测试：两个虚构网点、三辆虚构车辆和五个虚构需求点均只在内存中生成。示例安排四个需求点，并将超载的第五个点列为未安排。坐标、道路距离和时间均为演示估算，结果带「虚构测试」标识，不可保存为正式方案，不可用于投标或实际配送。

真实规划步骤：

1. 通过原网点管理页面维护并核对真实网点；系统只会将已分配车辆的网点地址提交给高德。
2. 在多网点页面为每辆车填写名称、所属网点、载重和当天发车时间；同一网点可配置多辆车。
3. 手动填写需求点或从已解读的招标文件导入位置候选，逐项核对名称和地址，再填写实际重量、送达时间窗及卸货分钟数。每次最多 10 辆车、14 个需求点。
4. 点击规划。系统先按最晚送达时间排序，在可用车辆中优先考虑距离需求点较近的发车网点；每段通过高德驾车服务取得道路距离和时长，逐项检查载重和时间窗。早到车辆会等待至窗口开始，卸货耗时会影响后续送达。需要返程时分别计算每辆车返回各自网点的路线。
5. 查看每辆车的出发网点、停靠顺序、载重、预计到达和服务时间，以及未安排原因。可保存公司内的路线方案快照，重载历史输入重新规划，也可导出路线示意图 PNG 和配送明细 CSV。

时间窗按同一天的本地时间填写，不支持跨日窗口；窗口限制的是开始送达/服务的时间。每车执行一趟，不拆分需求点、不考虑多趟装载。算法是启发式，不保证最短路线或找到所有可能的可行解；「未安排」表示当前安排未找到符合约束的车辆，不代表问题必然无解。预计时间使用规划时道路服务返回的估计值，不是指定未来发车时刻的实时交通预测。请复核地址定位、道路、实际车辆及配送时间后使用。

新规划的 PNG 是道路轨迹示意图，没有高德地图底图；旧版单路线仍保留原有高德地图导出。当前不覆盖容积、车型禁行、冷链、车辆排班、多趟配送或实时调度，也不替代配送业务系统。这些需取得真实网点、车型和业务约束后进一步设计。保存的方案属于用户输入和规划快照，更新网点或道路后需重新计算。

真实规划需要后端配置高德 Web 服务 Key，并将用户确认的地址发送高德；可能产生多次地理编码和道路路线请求。系统限制请求频率并在高德限频时重试；如果高德返回的门牌号与输入不符，规划会停止。请核对页面展示的高德定位地址与坐标，门牌号一致也不能保证入口位置准确。升级后重启后端，并刷新或重新部署前端。
