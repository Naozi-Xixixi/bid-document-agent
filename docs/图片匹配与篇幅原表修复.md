# 图片匹配、篇幅和招标原表

本次调整作用于图文正文生成及网页 Word 导出链路。

- 自动图片：先排除图片 OCR 中的合同、证照、发票、个人证件。当前企业证据保持原有检索；没有合适图片时，只在用户选定的历史投标案例中寻找与章节主题相符的示意图。图片自身须有正向内容证据，不用来源文件标题代替内容匹配。历史示意图有参考说明，不作为现行资质证明。只允许自动/项目图片模式使用这种回退，禁用图片和仅有效证照模式不受影响。
- 字数：默认上限也执行生成后校验。统计可见文字，排除 Markdown 结构和资源标记；图注和核实提示计入。明确篇幅目标使用 ±10%，默认上限不设凑字数下限。最多三次模型校订，仍不达标则返回明确错误并保留已保存正文，不截断表格或静默保存超限内容。固定招标表单优先保留原文，不参与删减凑字。
- 原表：从本项目上传的 PDF 矢量边框或 DOCX 表格提取报价、开标、响应、偏离类表单。保留列宽比例、行高、合并格、空白栏、签章及表后原文。正文使用可编辑表格，并保存结构元数据。网页预览、模板 Word、原生 Word 使用同一结构。表格行列被编辑破坏时，模板导出提示错误。宽表不再擅自改为两列。

边界：无可提取边框的扫描表、跨页复杂表、同页多个无法区分的表不宣称完整保真；需要对照招标原文核验。历史图的自动匹配不等于证明其现行有效。未确认报价保持空栏，并提示正式提交前补充。

补充：固定投标函等带签章的单页原文可直接保留；图片回退只按当前小节检索，并排除企业名录、认证名单与人员/报告等证明小节。限字校订不再重新注入整段项目和知识库上下文，避免压缩时再次扩写。原表单独起页，带序号的宽表跨页重复表头。

自动历史配图增加语义审核：候选图片仅提供自身 OCR，按当前小节判断具体业务是否直接相关。最多审核 12 张候选，使用已配置的正文场景模型，30 秒超时。模型返回无匹配、无效编号、非法 JSON 或调用失败时不强行配图；手动选择的素材仍由用户确认。
