# 高级配送约束模拟

在「示例配送公司配送路线图」中选择「高级配送约束模拟」。页面默认加载虚构测试数据，不修改公司网点、订单或车辆资料。模拟结果不得用于真实发车或作为实际配送能力证明。

默认样例：一家虚构配送中心、一所虚构学校、三辆虚构车。一份订单有 3 个不可拆分包装单元，每件 500 kg、1.5 m³，允许按单元拆送，要求 2–8℃；冷链车设定为 4℃，载重 800 kg、容积 2 m³、最多 3 趟，23:00 发车。订单窗口从 2026-10-30 23:50 到 2026-10-31 02:00（东八区）。另有一辆车在虚构道路上禁行，一辆车温度不满足。示例将订单拆为三趟，送达服务开始时间分别为 23:50、次日 00:40、次日 01:30。

算法按包装单元做有界枚举，车辆每趟总重量与总体积不能超过容量；返回原网点并经过配置的装载时间才能开始下一趟；只有车辆设定温度落在订单允许范围才可承运；窗口与工作班次使用带时区的完整日期时间。模拟道路是有方向的矩阵，缺失路段或指定车辆禁行均不可用。测试状态「模型内最优」表示在当前有限输入和模型中搜索完毕，目标依次为最多完成包装单元、最少道路距离；搜索超时或达到节点上限时只返回已找到的最好方案，不承诺最优。最多 4 辆车、8 个拆分单元、5 趟/车、5 秒。订单不允许拆分时，所有单位作为一个整体装载。

「模拟拥堵」将虚构道路行驶时间增加三倍；「模拟车辆禁行」禁止当前所有车辆使用虚构路段；二者之后重新求解。另一个样例将第一件标记为已完成、第一趟已使用且车辆均已返仓，重排时保留已完成数量并仅安排剩余两件；系统拒绝车辆处于非网点位置的重排输入。它仍是离线仿真，不接入 GPS、真实订单进度或实时路况，也不处理在途车辆的当前装货；不能称作生产实时调度。

另提供货车单路段查询：输入高德货车服务所需的实际车辆等级、尺寸、总重、核定载重、轴数、车牌、车型和起终点坐标，使用高德货车路径接口，而不是普通小车路线。未授权或接口失败时不会退回普通驾车；限行状态未知、起终点限行或途经限行均不会标记为可通行。该接口需要适用的高德权限，可能收费。新增有限规模货车排线：提供每个地点的真实经纬度、每辆车的真实车辆参数，系统按车辆分别请求货车道路矩阵，将限行或未知路段排除后交给上述约束求解器；最多 4 个地点、2 辆车、24 次道路请求。页面明确提示这些请求可能收费。实际高德货车权限尚未联调，接口行为已使用模拟响应测试。高德结果也不能替代现场道路标志、通行证和企业审核。

高德货车服务文档：[货车路径规划基础版](https://lbs.amap.com/api/logistic-service/guide/wagon_path/truck-route-plan-basis)。未来时间路线是独立的收费物流接口，参见[货车未来时间路径规划](https://lbs.amap.com/api/logistic-service/guide/wagon_path/hctime-route-plan)。上述货车单路段查询和货车矩阵排线均是当前时刻的道路快照，并不预测未来发车时段。

要投入实际配送，还需要企业提供真实网点、包装拆分规则、车辆参数、温度设备、车辆在途载货、车辆定位和订单状态，以及开通货车和必要的未来时段服务。届时应完成实时数据接入、在途已装载订单锁定、司机确认、调度日志、恢复与并发等设计及真实业务验收；虚构样例无法验证这些事项。
