# 暗标 Word 导出检查

图文正文的 Word 导出在项目类型为暗标、选择「精简暗标版」、或勾选「按暗标检查」时启用检查。导出前先填写身份识别词，每行一个，包括企业全称和简称、品牌、关联企业、人员姓名、独有地址和其他招标文件禁止出现的身份信息。当前登录公司的名称也会自动加入词库；手工输入的词保存在本浏览器当前公司下，需要由使用者核对完整性。

导出流程先生成 Word 并在需要目录时更新页码，然后清除作者、最后修改人及公司属性，对最终下载的文件检查：

- 正文、表格、文本框、页眉页脚、脚注尾注、批注和其他 Word XML 内容中的词库、网址、邮箱和手机号码；检查可跨 Word 文本片段和空白字符匹配。
- 文件属性、图片替代文本、外部关系、批注和修订；未清除的作者、批注、修订、外部链接和不可检查内容均报告问题。
- 每个嵌入图片都运行本地 OCR；识别失败、图片格式不支持、多帧图片及其他无法检查的情况会阻止导出。问题清单提供 Word 部件、段落序号或媒体文件名；图片附缩略预览和 OCR 文字。
- 检查存在问题时不能继续下载。没有问题时，使用者需要确认词库及全文，并逐张复核图片中的 Logo、水印、人员和其他身份线索，才能下载本次检查过的文件。修改后须重新导出和检查。

OCR 和词库不是匿名保证：不在词库的姓名、地址、变体、图片中无法识别的文字，以及非文字标识可能遗漏。应结合原始文件和招标文件人工审查。检查不执行自动正文脱敏，也不保证符合每个招标项目的版式要求。仅覆盖图文正文工作台的 Word 导出；目录、协作 Markdown 草稿及其他工具产生的文件不能视作已检查的暗标。

检查需要后端安装 requirements-ocr.txt；嵌入图片逐张识别会耗时。上传的待检 Word 不超过 100 MB，解压总大小不超过 512 MB。带目录的导出仍需要原有 Windows Microsoft Word 分页服务。升级后需重启后端并重新构建或刷新前端。
