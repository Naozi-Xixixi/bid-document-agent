# 历史项目删除

在“招标文件和大纲生成 → 选择历史项目”列表中，点击项目右侧的“删除”，核对确认弹窗里的项目名称与范围后再确认。点击“取消”不会发送删除请求。

## 删除范围

- 删除当前公司中所选项目的历史记录、解析结果、大纲、正文及项目关联数据。
- 清理不再被使用的上传副本。电脑上最初选择的源文件不会被删除。
- 其他项目和企业知识库仍在使用的文件保留原路径，避免共享资料失效。
- 删除成功后列表及当前选中项目的缓存同步更新。此功能没有回收站。

## 运行与错误处理

- 正在解析、上传或生成的项目暂时不能删除；应等待操作结束或先停止生成。
- 请求进行中禁止重复确认及关闭弹窗。
- 服务端未确认成功时，不提前从列表移除项目，弹窗显示具体错误。
- 项目记录已经删除但部分磁盘副本未能清理时，页面单独显示清理警告。

## 验证

后端删除测试使用独立的临时数据库和文件目录，覆盖关联记录清理、共享文件保留、公司隔离、活动任务、路径边界和失败处理。前端测试使用模拟接口检查确认/取消、重复操作、失败保留及选中项目缓存清理，不删除已有业务项目。

## 来源说明

历史列表和删除确认弹窗会显示上传招标文件的原始文件名、大小及解析状态；粘贴资料、没有解析资料、来源读取失败分别提示。旧版项目的参考附件另行列出。列表使用项目关联标识查询轻量解析状态，不为显示来源逐项读取正文。
