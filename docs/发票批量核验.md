# 发票批量核验与结果留存

在首页打开「发票智能核验」。支持单次选择 1–30 个 JPG、PNG、WEBP、BMP 或 PDF，单文件最大 20 MB、每批最大 100 MB。上传后批次和原文件保存在当前公司数据空间，后台逐张识别；不支持或超过大小限制的单个文件会显示失败，不影响其余文件。刷新页面后可在历史批次中重新打开记录。

识别完成后，选中一张发票，对照原件修改并保存字段。本地校验只检查字段完整性和格式，不代表税务真伪结论。点击官方平台链接，按官方要求人工填写字段、完成验证码并查看结果。根据实际结果上传截图和备注，再记录「通过」「未通过」或「待复核」。其中通过和未通过要求上传有效图片截图（最大 10 MB）。系统记录操作账号和服务器时间；上传截图本身不能证明结果真实或由官方出具。

字段发生变化后，当前人工结果和截图关联会失效，必须重新查验。操作历史保留变更前后的记录及历史截图，可按记录下载。并发操作使用版本号防止覆盖，提示冲突时请先保留自己的修改，再加载最新记录。汇总报告为 UTF-8 CSV，可用 Excel 打开；报告中的查验状态均明确标为人工记录。

处理失败可单张重试；服务中断后若有待处理或识别中的记录，可点击「继续未完成和失败项」。未成功保存原文件的条目需重新上传。历史记录和文件会一直保留，需按照企业的数据保留要求定期备份公司业务数据库和上传目录，清理政策由管理员另行制定。

系统没有接入税务或财政平台的自动核验接口，也不会绕过验证码；正式接入自动查验需要取得适用的数据接口和授权。升级代码后需要重启后端并刷新或重新部署前端；本地 OCR 需在后端环境正确安装。
